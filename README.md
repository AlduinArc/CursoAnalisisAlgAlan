# Curso de Análisis de Algoritmos

Repositorio correspondiente al curso de Análisis de Algoritmos. En este repositorio se almacenarán los laboratorios evaluativos, los ejercicios realizados durante las clases y los recursos utilizados para realizar mediciones y benchmarks.

## Estructura del repositorio

* `laboratorios/`: contiene los cinco informes de laboratorio evaluativos realizados durante el semestre.
* `ejercicios-clase/`: contiene los ejercicios y programas desarrollados durante las sesiones prácticas.
* `benchmarks/`: contiene scripts utilizados para medir tiempos de ejecución y generar gráficas.
* `README.md`: documento principal de presentación y documentación del repositorio.
* `.gitignore`: contiene los archivos y carpetas que Git debe ignorar.

## Objetivos

El repositorio permitirá organizar el trabajo realizado durante el curso y mantener un historial de los avances mediante Git y GitHub.

Entre los principales objetivos se encuentran:

1. Practicar el uso de Git y GitHub.
2. Implementar y analizar algoritmos.
3. Medir tiempos de ejecución.
4. Documentar los resultados de los laboratorios.

# Semana 2

Se creó un entorno virtual para aislar las dependencias del proyecto.

El entorno se creó con `python -m venv venv`.

En Windows se activa mediante `.\venv\Scripts\Activate.ps1`.

Las dependencias instaladas se guardaron usando `pip freeze > requirements.txt`.

Para reproducir el entorno, se debe crear y activar un entorno virtual y ejecutar `pip install -r requirements.txt`.

Los archivos de esta semana contienen el ejercicio de refactorización PEP 8 y el clasificador de años bisiestos.
